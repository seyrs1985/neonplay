# Bubble Storm (bubble-storm)

> 一句话卖点：**无广告的泡泡龙，每天一张全球同题的起始阵**——瞄准、弹墙、三连爆，悬浮簇整片塌落，准确率与链式得分定段位。

- **缝合来源**：Bubble Shooter 经典（瞄准弹射+同色三连+悬浮塌落）× 每日种子阵型（日期哈希全球同题）× 连击链式计分（Brickstorm 倍率经济）
- **目标玩家**：泡泡龙品类基本盘（休闲游戏史上最大品类之一，全年龄）；bubbleshooter.net 式"品类词长尾"流量；被 App 端插屏劝退的用户
- **单局时长**：3-8 分钟（40 发子弹/失败即终）

---

## 〇、差异化红线回答（LESSONS.md 第 8 条）

**"比 Google 搜索前 3 名多做了什么？"**——泡泡龙品类需求巨大（运营 neon-solitaire 调研已引用 bubbleshooter.net 作为"品类词+长尾可吃"范例），web 供给多但体验两极：老站功能全但界面老旧/广告密，新站换皮无留存。本作：

1. **每日种子阵型全球同题**——`mulberry32(YYYYMMDD)` 生成起始阵与弹色序列：全球玩家打同一张开局，分数可比、天天新鲜。门户版全部随机无每日。→ 满足红线"组合两个已有玩法"（经典泡泡龙 × 每日同题竞速框架，第五次移植站内种子基建）。
2. **链式计分与悬浮塌落的"一波暴富"**——塌落按泡泡数 ×20 重奖，引导玩家追求"打断关键支撑"的解法深度而非无脑消色。→ 满足红线"组合已有玩法创造新体验"（经典规则 × 连击倍率经济）。
3. **无广告/秒开/大触区/双语**——对品类 App 端"插屏+体力"模式的正面回答（同 neon-solitaire 打法）。
4. **品类补全**——泡泡龙是休闲游戏史最后几个"全站缺失"的主要品类之一（aim+弹墙瞄准是全新操作动词）。

## 一、调研依据（2026-09-14）

### 热门拆解（含留存机制）
| 游戏 | 核心循环 | **留存机制** | 借鉴→本土化 |
|---|---|---|---|
| **Bubble Shooter 经典系**（bubbleshooter.net 等，品类词流量范例） | 瞄准弹射→同色三连→悬浮塌落 | 关卡海量+广告 | 经典规则+弹墙瞄准；补每日/段位/分享 |
| **Bubble Witch 系**（King，休闲巨头） | 同上+剧情关卡 | 生命值+关卡地图+社交送命 | 生命值墙不做；"链式暴富"替代理性化付费 |
| **Ball Blast/BBTAN 系**（变形品类） | 射弹+数值 | 每日任务 | 连击倍率经济（Brickstorm 模式复用） |

### 同构分析（饱和度）
- 供给极端饱和（诚实评估为全站候选中最高）：卷 IP、卷关卡数、卷体力墙。
- web 老站：功能全但 UI 老/移动端一般；新换皮站：无留存无每日。
- 空白维度：每日种子阵（无供给）+段位（无供给）+站内四类分区缺"瞄准射击"动词。

### 异构分析（NeonPlay 现有 17 款的缺口）
现状四类分区+pending 十款。
- **缺口：瞄准弹射=0 款**——站内无一款"角度+弹墙预判"玩法（neon-hoops 是拖拽投掷非弹墙瞄准）；操作动词补"瞄准弹射"。
- 受众：全年龄跨度最大（泡泡龙无年龄/性别门槛），与站内各品类都互补。

### 组合为何成立
- 泡泡龙的"悬浮塌落"是品类最强爽点（一片塌落的暴富感），链式倍率把它变成可追求的技术目标——规则自带深度，无需发明新机制。
- 每日种子阵解决泡泡龙"无限随机不可比"的老问题，段位让"今天这张阵你多少分"成为可晒话题。
- 站内基础设施全复用：种子（四度移植）、六键留存（标准化）、分享卡（标准化）、QA 钩子（标准化）——设计增量集中在弹道与六边形数学（本文档已给公式与测试向量）。

## 二、玩法设计

### 核心算法（测试向量已脚本验证，公式直接照抄；T3 曾暴露偏移陷阱——以本文档公式为准）

```
六边形网格：偶数行 8 列，奇数行 7 列（右移半格，奇数行末列空缺）
邻接公式（关键！奇偶行方向不同，写反会导致不相连误判）：
  偶数行: (r,c-1)(r,c+1)(r-1,c)(r-1,c+1)(r+1,c)(r+1,c+1)
  奇数行: (r,c-1)(r,c+1)(r-1,c-1)(r-1,c)(r+1,c-1)(r+1,c)
弹道：直线飞行，遇墙/泡泡反射（圆-圆碰撞，泡泡半径 16px，子步进 240Hz 防隧穿）
瞄准预览：从发射点显示 1 次弹墙反射的虚线轨迹
吸附：碰撞后按行奇偶吸附到最近空格位
消除：同色连通块 ≥3 弹出（BFS flood）；
悬浮检测：从顶行 BFS 锚定，未锚定泡泡整簇掉落（×20 分/个）
发射数：每 6 发未消除→顶部下压一行（难度递进）；泡泡越界底线=失败
```

### 规则（MVP 共 6 条）
1. 底部发射器，拖拽/移动瞄准（显示 1 次弹墙反射预览线），松手/点击发射。
2. 同色连通 ≥3 消除（10 分/泡）；消除后**悬浮泡泡整簇塌落**（20 分/泡）。
3. 每消除 1 泡连击 +0.1 倍率（3 秒窗口，封顶 ×3），失败发射清零。
4. 每 6 发未消除泡泡阵下压一行；泡泡越过底线→局终，按分数结算。
5. **每日阵型**：`mulberry32(YYYYMMDD)` 生成初始 6 行阵与弹色序列（仅从场上存在的颜色抽取——公平惯例），全球同题；**经典模式**：随机种子无限局。
6. 结算：总分/消除数/塌落数/段位；NEW BEST 扫光。

### 段位阶梯（按单局总分）
| 段位 | 分数 | | 段位 | 分数 |
|---|---|---|---|---|
| 🏆 传奇 | ≥15000 | | 🟡 黄金 | 3000-4999 |
| 🥇 大师 | 10000-14999 | | ⚪ 白银 | 1500-2999 |
| 💎 钻石 | 7500-9999 | | 🟤 青铜 | <1500 |
| 🥈 白金 | 5000-7499 | | | |

### 核心循环（4 步）
1. **读阵**：扫描大簇与"承重泡"（拿掉会让上面塌落的关键泡泡）。
2. **瞄准**：弹墙角度计算，预览线校准——从缝里绕到背后的技术快感。
3. **爆发**：三连弹出+悬浮塌落的连锁暴富，倍率飙升。
4. **承压**：下压行逼近底线，分数冲刺与止损的张力；明天新阵再来。

### 操作方案
| 端 | 操作 |
|---|---|
| 触屏 | 按住发射器拖动瞄准（预览线实时更新），松手发射 |
| 鼠标 | 移动瞄准+点击发射 |
| 键盘 | ←→ 微调角度（2° 步进）+ 空格发射（角度表常驻） |

### 美术方向（霓虹色板）
- 底 `#0a0a18` 深空；泡泡=六色霓虹玻璃球（青 `#00e5ff`/品红 `#ff2d95`/金 `#ffd54a`/紫 `#7c4dff`/绿 `#39ff88`/橙 `#ff9e40`），高光点+内发光。
- 弹道预览=白色虚线+落点圈；发射拖尾；消除=同色粒子爆裂；塌落=整簇重力下坠+落地弹跳消失+金色分数雨。
- 下压行=顶部金属推板（银灰）压下动画+警告红光；失败=推板越线震屏+黑屏定格。
- 每日阵开场卡=`DAILY BOARD #N 全球同题`（复用聚光灯样式）。

## 八、验收标准

1. 线上 `/bubble-storm/` HTTP 200；375×667 游戏框首屏 58vh（一票否决项）；无控制台报错。
2. **玩法验证红线（LESSONS 第 9 条）**：qa_playtest 用 `__qa.shoot()` 按测试向量坐标制造三连→断言消除计分；构造悬浮阵→断言塌落与 ×20 分；人为 6 发未消→断言下压行；泡泡越线→断言失败结算；全程 `window.onerror` 零报错。纯布局 pass 不算可玩。
3. **算法 QA（本作特有红线）**：`__qa.grid()` 构造三组测试向量（对应本文档 T1/T2/T3）→ 断言消除数/掉落数/剩余数与向量一致；同日两次加载每日阵逐格一致（确定性）。
4. **留存验收（模板硬性要求）**：
   - 刷新后 best/Top10/streak/daily 戳不丢（逐键核对第三节清单）；
   - 连胜跨天 +1/断档归 1/补签卡消耗（改本地时间验证）；
   - 分享卡可生成（canvas 非 blank）含站点链接，剪贴板降级可用；
   - 全部存档键名与第三节清单一一对应。
5. 数值正确性：消除 10 分/塌落 20 分、连击 3 秒窗口封顶 ×3、6 发下压、段位阈值边界（9999=钻石、10000=大师）。
6. 物理底线：弹道子步进无隧穿、吸附无重叠、60fps 稳定、时间基驱动后台不失步。
7. UI 文案走 np_core L 字典（`np_lang` 联动）；键盘微调角度可完成一局。
8. IndexNow 提交；`STATUS.md` 运营日志追加；开发侧按惯例写 `data/run_stats.jsonl`；iOS Safari + 桌面 Chrome 冒烟通过。

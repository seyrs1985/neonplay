- 站内 tile-rush 已验证层叠 DOM 渲染心智，引擎复用度高。

## 二、玩法设计

### 自由牌规则（MVP 定义，简化自经典但保留核心推理）
1. 牌=1 格 footprint，分层堆叠（层 1 在底）。
2. **自由牌**：同 (x,y) 的更高层无牌，且 **左邻或右邻至少一侧为空**（同层判定）。
3. 点击两张自由牌且同面 → 消除（折线辉光+粒子）。
4. 无可消对 → **自动洗牌**剩余牌面（免费，计数进结算罚分 −100/次；验证实测 600 局 0 次触发——自动洗牌仅为理论兜底）。
5. 清空全部 → 通关；计分=基础 100/对 × 连击倍率（4 秒内连消 ×1.1 递进封顶 ×2）+ 时间分 `max(0, 400 − 秒数)` + 零洗牌加成 100。
6. 模式：**休闲**（金字塔 28 牌/8 面）/ **标准**（宽阵 48 牌/24 面）/ **挑战**（双塔 56 牌/28 面）/ **每日牌局**（日期种子在标准布局上生成牌面，全球同题，用时计戳）。

### 布局数据（3 张，已脚本验证：600 局种子全部零洗牌可解）

```js
// {层:[(x,y)...]}，层 1 为底；牌面由种子分配（每面成对）
const LAYOUTS = {
 casual:  {1: 6×4 满阵(24)              , 2: 2×2 中心(4)   },  // 28 牌 14 对
 standard:{1: 8×5 满阵(40)              , 2: 4×2 中心(8)   },  // 48 牌 24 对
 expert:  {1: 8×6 满阵(48)              , 2: 四角 2×1×4(8) },  // 56 牌 28 对
};
```

### 出牌算法（已脚本验证）
```
1. faces: 成对面表按种子洗匀 → 赋给全部格位（确定性）
2. 贪心求解模拟: 反复取"任一自由同面对"移除；卡死→整阵面色重排（自动洗牌语义，计数）
3. 实测: 3 布局 × 200 种子 = 600/600 零洗牌可解, 0.1s/局
   （每日牌局 mulberry32(YYYYMMDD) 与验证行为等价；提示系统复用同一求解器找可消对）
```

### 核心循环（4 步）
1. **透视**：扫"哪些牌能取"（顶空+侧通），层叠结构在心里分层。
2. **配对**：同面自由牌配对消除，露出下层新选择。
3. **规划**：同面多对时先消谁能解锁更多？偶发洗牌是兜底不是常态。
4. **刷优**：用时入段位；明天新牌面（布局轮换）再来。

| 端 | 操作 |

| 键盘 | 方向键+层切换(PageUp/Down)移动焦点 / Enter 选中 / H 提示（可达性辅助模式） |

### 美术方向（霓虹色板）
- 底 `#0a0a18` 深空；牌=玻璃拟态+emoji 大字，自由牌青 `#00e5ff` 描边微光、被压牌压暗 40%（可访问性可视化）。
- 选中=金 `#ffd54a` 抬升辉光；消除=折线辉光+同面色粒子；层间阴影+半格错位制造立体感。
- 通关=全阵 confetti+用时翻滚+零洗牌"PERFECT DEAL"金标；洗牌=全牌翻转让位+警告提示。

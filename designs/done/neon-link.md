# Neon Link (neon-link)

> 一句话卖点：**连连看的干净网页版**——两张同款、三折线以内连通路就消；每个牌局都由"修复式构造"保证不用洗牌就能通关，每天全球同一张牌面。

- **缝合来源**：Onet/连连看（经典连线消除）× 砖块游戏连击经济（快速连消倍率）× 每日种子牌局（日期哈希全球同题）
- **目标玩家**：连连看国民级记忆人群（中文市场 20 年心智）；Onet/ Mahjong Connect 欧美玩家；通勤碎片时间
- **单局时长**：休闲 1-2 分钟 / 标准 2-4 分钟

## 〇、差异化红线回答（LESSONS.md 第 8 条）

**"比 Google 搜索前 3 名多做了什么？"**——Onet web 供给不少（MSN/GameSnacks/Agame 门户版），但普遍为旧式换皮：无确定性牌局、无留存体系、移动端触区小。本作：

1. **修复式构造保证"零洗牌可解"**——生成算法内置修复网（种子确定性），脚本验证 100/100 种子无需洗牌即可通关：随机发牌的门户版经常中途死局靠洗牌续命。→ 满足红线"组合两个已有玩法"（连线消除 × 构造式发牌公平机制；方法论第五次交付）。
2. **留存五件套自带**——每日同题牌局+连胜+时间段位+分享卡（品类 web 版普遍没有每日/段位概念）。
3. **无广告+双语+竖屏大触区**——门户版通病逐项反着做；中文市场"连连看"国民记忆点直接吃 `连连看 在线` 长尾。

## 一、调研依据（2026-09-14）

### 热门拆解（含留存机制）
| 游戏 | 核心循环 | **留存机制** | 借鉴→本土化 |
|---|---|---|---|
| **Onet Connect Classic**（[GameSnacks](https://gamesnacks.com/games/onetconnectclassic)/[MSN](https://www.msn.com/en-in/play/games/Onet-Connect/cg-9n04sk19zcnf) 门户版） | 连同款→三折线内→消除 | 门户推荐位流量，无自有留存 | 连线消除+边界可走规则；补每日/段位/分享 |
| **Tile Match/羊了个羊 系**（tile-rush 已立项） | 托盘三消 | 每日一关文化 | 相邻品类佐证：消除类对"每日牌局"反应好 |
| **连连看**（中文国民游戏，20 年心智） | 同上 | QQ 游戏时代=房间竞技+熟练度 | "连连看 在线"长尾直连 |

### 同构分析（饱和度）
- web 供给较拥挤：门户 embed 多为同源 HTML5 模板，卷主题皮肤；确定性牌局/留存体系为空白。
- 与站内 tile-rush（托盘三消）构成"消除双壁"：连线 vs 托盘，机制族谱相邻但操作动词不同（路径规划 vs 槽位取舍）。

### 异构分析（NeonPlay 现有 17 款的缺口）
- **缺口：路径规划=0 款**——益智系无一款以"寻路可达性"为核心判定（BFS 折线）；操作动词补"规划连线"。
- 受众：连连看国民记忆（25-45 中文用户）+ Onet 欧美玩家；碎片时间型。

### 组合为何成立
- 规则 3 秒讲完（同款+连得着=消），路径规划的深度在"先消哪对才能让后面的连得上"——浅规则深规划。
- 构造式发牌让"这局无解"的品类传统抱怨彻底消失；每日同题让用时可比。
- 工程最轻：BFS≤2 折（20 行）+DOM 网格+贪心修复网，与站内六款 R1/R2 并行无冲突。

## 二、玩法设计

### 规则（MVP 共 6 条）
1. 网格牌面（emoji）；点击两张**同面**牌：若存在 ≤2 个转折（3 段线）的通路（可在牌阵**外围绕**，经典规则）→ 消除并闪现连线；否则两张抖动提示。
2. **连线动画**：消除时折线路径辉光描绘 300ms——路径可视化是本作的爽点与策略教学（看懂"哪里通"）。
3. 无可连对时**自动洗牌**剩余牌面（免费，计数进结算）；构造算法保证极少触发（测试 100 局 0 次触发）。
4. 计分：每对基础 100 分 × 连击倍率（3 秒内连续消除：×1→×1.5→×2→×2.5 封顶）；通关加 `max(0, 300 − 秒数)` 时间分；洗牌一次 −100。
5. 提示 3 次：高亮一对可连牌。
6. 模式：**休闲** 6×5（30 牌/15 对/8 面）/ **标准** 8×6（48 牌/24 对/12 面）/ **每日牌局**（日期种子，标准规格，全球同题，通关用时计分计戳）。

### 出牌算法（已脚本验证，可直接实现）
```
1. faces: 8/12 种面按对数随机（种子）→ 洗匀 → 填入网格
2. 贪心消除模拟: 反复找"任一可连对"（BFS ≤2 折, padded 网格边界可走）移除
3. 卡死→修复网: 随机交换两张异面牌面, 重试（确定性种子）
4. 实测: 8×6/12 面 100 种子 → 100% 零修复可解, 平均修复 0 次, 4ms/局
   （每日牌局同算法+日期种子=确定性同牌面；JS mulberry32 与文档验证等价）
```

### 段位阶梯（按标准档通关用时）
| 段位 | 用时 | | 段位 | 用时 |
|---|---|---|---|---|
| 🏆 传奇 | <60s | | 🟡 黄金 | <150s |
| 🥇 大师 | <90s | | ⚪ 白银 | <240s |
| 💎 钻石 | <120s | | 🟤 青铜 | ≥240s |
| 🥈 白金 | <120s+零洗牌 | | | |

### 核心循环（4 步）
1. **扫面**：同款牌的位置记忆+通路想象（转角在哪、绕外圈还是穿中场）。
2. **连线**：消除+折线辉光——路线被"画"出来的反馈。
3. **连锁**：快消提倍率，牌面越薄通路越开（正反馈滚雪球）。
4. **刷优**：通关用时入段位；明天新牌面再来。

### 操作方案
| 端 | 操作 |
|---|---|
| 触屏 | 点两张同面牌（≥44px 触区）；点错第二张自动取消首张 |
| 鼠标 | 同触屏 |
| 键盘 | 方向键移动光标 / Enter 选中 / H 提示 / S 洗牌（辅助可达） |

### 美术方向（霓虹色板）
- 底 `#0a0a18` 深空；牌=玻璃拟态圆角块+emoji，同面牌选中=青 `#00e5ff` 辉光抬升。
- **连线=金 `#ffd54a` 折线辉光描绘**（消除动效核心）；消除爆裂=牌面色粒子。
- 连击胶囊右上角弹跳升档；洗牌=全牌翻转让位动画；通关=牌阵 confetti+用时翻滚。

## 八、验收标准

1. 线上 `/neon-link/` HTTP 200；375×667 游戏框首屏 58vh（一票否决项）；无控制台报错。
2. **玩法验证红线（LESSONS 第 9 条）**：qa_playtest 用 `__qa.solveStep()` 连消 3 对→断言连线动画与计数；循环至清空→断言通关面板与用时；全程 `window.onerror` 零报错。纯布局 pass 不算可玩。
3. **生成 QA（本作特有红线）**：随机抽 5 个日期种子，代码断言：牌面确定一致（同种子两次生成逐格相同）、贪心模拟可清空（零洗牌）、牌对数=格子数/2。
4. **路径判定 QA**：直线/一折/二折三例均连、三折拒绝、跨边界绕行（首列到末列）连通、被牌阻挡路径拒绝。
5. **留存验收（模板硬性要求）**：
   - 刷新后 best/Top10/streak/daily 戳不丢（逐键核对第三节清单）；
   - 连胜跨天 +1/断档归 1/补签卡消耗（改本地时间验证）；
   - 分享卡可生成（canvas 非 blank）含站点链接，剪贴板降级可用；
   - 全部存档键名与第三节清单一一对应。
6. 数值正确性：计分公式（100×连击倍率）、时间分、洗牌 −100、段位阈值边界（119.9s=白金、120s=钻石）。
7. UI 文案走 np_core L 字典（`np_lang` 联动）；触区 ≥44px、键盘可完整通关休闲档。
8. IndexNow 提交；`STATUS.md` 运营日志追加；开发侧按惯例写 `data/run_stats.jsonl`；iOS Safari + 桌面 Chrome 冒烟通过。

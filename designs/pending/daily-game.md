# 全站每日一游 + 访问 Streak（daily-game）

> 一句话卖点：**给用户一个明天再来的理由**——首页每天聚光灯一款游戏（客户端按日期确定性轮换），连续访问点亮 🔥streak，DAU 翻倍 = 广告库存翻倍，比拉新便宜一个数量级。

- **类型**：现有站点功能增强（站点 chrome / 首页，纯前端，不碰任何游戏本身）
- **来源**：用户运营决策直派（2026-09-11 流水线头脑风暴清单·捕获段，与 brickstorm-daily 同属留存钩子专项）。评分：搜索需求 1 / 竞争空白 3 / 变现意图 4 / 开发成本低 3 / 复访价值 5 = 16/25（留存直派）
- **差异化红线回答**：同类小游戏站首页是静态列表，没有"今天来玩什么"的时间维度；Wordle 已验证"每日 + streak"是最便宜回访机器

## 实现

1. **今日聚光灯**：纯前端 JS——对当前日期做确定性哈希，从站点游戏列表选出"今日游戏"，首页顶部渲染聚光灯卡（游戏 emoji+标题+一句话+立即玩按钮）。无需重建、无需后端，全球用户当天看到同一款
2. **Streak**：localStorage 记 `np_streak`（当前连续天数/最后访问日期）：跨天访问 +1，断一天清零；聚光灯卡上显示 🔥N；当日首次访问才结算，防同日刷新刷数
3. **文案**：全英文 + 站点 i18n 字典（data-i18n / i18n.js 的 hall 命名空间补键），预留 zh 翻译
4. **布局红线**：375×667 首屏——聚光灯卡紧凑（一行式横条或 ≤120px 高卡），不得把游戏网格挤出首屏折叠线以下；触屏目标 ≥44px

## 数值/规则细节

- 轮换均匀性：用 `(days_since_epoch * 2654435761) % len(GAMES)` 类整数散列，避免某些游戏永远轮不到
- 今日游戏与被选中游戏的落地页互链（聚光灯卡 = 额外内链入口，SEO 顺带受益）

## 验收标准

- 改系统日期（或 mock Date）可见不同游戏被选中且全天一致；streak 跨天 +1、断档清零、同日刷新不变
- 375×667 首屏验收通过（聚光灯卡可见且不挤占游戏网格）；无控制台报错

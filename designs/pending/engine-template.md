# 公共游戏引擎模板抽取（engine-template）

> 一句话卖点：**给开发流水线换高速刀头**——把 9 款游戏各自重复实现的公共件抽成共享模板，新游戏单局实现成本降约一半，同样产能下试错次数翻倍。

- **类型**：站内基建（开发侧提速，非用户可见页面，不适用差异化红线与 SEO 验收）
- **来源**：用户运营决策直派（2026-09-11 流水线头脑风暴清单·加工段）。评分仅供排序参考：搜索需求 1 / 竞争空白 2 / 变现意图 2 / 开发成本低 5 / 复访价值 4 = 14/25（基建直派不受策划 17 分入队线约束）

## 目标

Brickstorm 靠复用 Breakout 的代码心智 12 分钟上线——证明复用率是本流水线的第一成本杠杆。本方案把"隐性复用"变"显性模板"。

## 抽取清单（按收益排序）

1. **canvas bootstrap**：HiDPI 缩放、resize 自适应、rAF 游戏循环、页面隐藏暂停
2. **粒子系统 + 震屏**：击破爆花、辉光、红闪（Memory Pairs/Brickstorm/Tic Tac Toe 各写了一份）
3. **玻璃拟态面板**：升级三选一 / 结算 / 暂停面板通用样式与开合动画
4. **localStorage 存档封装**：最佳分/最高波次/设置读写，键名规范 `<slug>_best` 等
5. **i18n 加载器**：内嵌 `var L={en,zh}` 字典 + `np_lang` 键读取 + `t(k)` 函数（各游戏内嵌重复）
6. **霓虹设计 token**：色板 CSS 变量（#0a0a18 / cyan / violet / pink / gold）、辉光工具类
7. **输入统一封装**：触屏（相对位移、touch-action:none、≥44px）+ 键盘 + 鼠标三端映射

## 实现约束

- 落点建议 `engine/assets/games/_shared/`，build.py 逐游戏拷贝或以相对路径引用——**硬约束：拷贝进 docs 后每款游戏必须保持自包含可玩（iframe 内不得引用站点级资源路径）**，具体打包方式由开发 Agent 依 build.py 现状定
- **分轮执行，禁止单轮大爆炸**：每轮迁移 1-2 款游戏到共享件并逐款回归（可玩、存档保留、i18n 不破、375×667 首屏验收），全部迁移完后再产出"新游戏脚手架模板"
- 不改变任何游戏的行为与数值

## 验收标准

- 每轮迁移后：所涉游戏可玩、localStorage 存档在、中英文切换正常、无控制台报错
- 终态：`_shared/` 模块 + 新游戏脚手架就位，后续新游戏文档可直接声明"基于脚手架"
